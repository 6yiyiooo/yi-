# Windows系统优化工具
> Python + Tkinter 编写的图形化Windows系统优化小工具，本项目仅作编程学习用途。

## ✨ 项目功能
- 图形GUI可视化操作，上手简单
- C盘垃圾文件扫描与清理
- 虚拟内存 `pagefile.sys` 管理
- 硬盘空间释放、文件迁移管理
- 操作日志记录，方便查看改动记录
- 使用Python内置Tkinter，无需额外安装大量第三方依赖

## 📥 下载
前往 (https://github.com/6yiyiooo/yi-) 下载打包好的 `yi优化1.0.exe`

## 📋 使用说明
1. **右键，以管理员身份**运行程序
2. 在图形界面选择想要执行的优化项目
3. 跟随弹窗提示确认操作
4. 部分系统设置修改完成后，**重启电脑**才能生效

## ⚠️ 风险警告（务必阅读）
> ⚠️ 本项目是学习演示项目，**使用前务必备份电脑重要文件！**
1. 清理系统文件存在风险，错误操作有可能导致系统异常。
2. 不要在生产服务器、存有重要工作资料的电脑随意运行。
3. 修改虚拟内存、系统文件相关设置请充分了解作用再确认。
4. 使用者需要自行承担使用本工具带来的所有后果。
